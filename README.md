# Pet Care Management System

## Project Description
A Java-based application for managing pet care activities
using MySQL as the database.

## Technologies Used
- Java
- MySQL
- JDBC
- IntelliJ IDEA

## Features
- Register a Pet
- View All Pets
- Book Appointment
- View Appointments
- Add Health Record
- View Health Records

## How to Run
1. Install Java and MySQL.
2. Create the required database.
3. Configure the database connection.
4. Run Main.java in IntelliJ IDEA.
